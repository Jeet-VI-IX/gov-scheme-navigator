# NMMSS (National Means-cum-Merit Scholarship Scheme)

**Category:** Education
**Ministry:** Ministry of Education, Department of School Education & Literacy
**Official source:** https://scholarships.gov.in/public/schemeGuidelines/NMMSSGuidelines.pdf

## Objective
Awards scholarships to meritorious students from economically weaker sections to prevent them from dropping out at Class VIII and to encourage them to continue studies through the secondary stage.

## Benefits
- ₹12,000 per year (₹1,000/month) scholarship, paid from Class IX onward.
- Continuable up to Class XII — a maximum period of 4 years.
- 100,000 fresh scholarships awarded each year, distributed via a fixed State/UT-wise quota.
- Disbursed directly to the student's bank account via Direct Benefit Transfer (DBT).

## Eligibility
- Parental income from all sources must not exceed ₹3,50,000 per annum (revised from the earlier ₹1,50,000 ceiling).
- Student must be entering Class IX as a regular student in a Government, Government-aided, or local body school.
- **Not eligible:** students in Kendriya Vidyalayas, Jawahar Navodaya Vidyalayas, Residential Schools run by Centre/State institutions (with boarding/lodging provided), or private schools.
- Must have scored a minimum of 55% marks (or equivalent grade) in the Class VII exam to sit the selection test in Class VIII (relaxable by 5% for SC/ST students).
- Must clear a State-level selection test (Mental Ability Test + Scholastic Aptitude Test) with at least 40% aggregate marks across both (32% for SC/ST students), and score at least 55% in the Class VIII exam.
- For continuation into Class X/XII: minimum 60% marks in Class X (relaxable by 5% for SC/ST), with clear promotion in the first attempt from Class IX→X and XI→XII.
- A student can avail only one scholarship under any Central Government scholarship scheme at a time.
- No scholarship is payable for studies abroad or for diploma/certificate-level courses.

## How to Apply
- Selection is via a State/UT-conducted exam (MAT + SAT) for Class VIII students, held in November each year.
- Eligible/selected students apply on the National Scholarship Portal (NSP): https://scholarships.gov.in
- Application is verified by State Government/UT Administration and then forwarded to the Ministry for sanction of funds.
- Scholarship is discontinued if the student fails to renew the application on NSP within the stipulated time each year.

## Notes for the assistant (grounding constraints)
- This is strictly a **Class VIII → Class IX transition** scheme — it is not for students already in Class IX or above who missed the Class VIII selection test. If the user is a student in Class IX–XII who never appeared for the NMMSS test in Class VIII, this scheme is not applicable (it's for continuation of an already-awarded scholarship, not fresh entry at those stages).
- If the user doesn't mention their current school type (Government/Government-aided/local body vs. private/KV/JNV/residential), flag this as missing information — school type is a hard eligibility filter here, not just a preference.
- If the user doesn't mention parental income, flag as missing information — the ₹3.5 lakh ceiling is a hard cutoff, not a soft signal.
